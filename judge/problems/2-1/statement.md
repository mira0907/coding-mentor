# 2-1 島嶼探險（簡單）

出處：講義第二章 實作 2-1

一張 R × C 的地圖中，`#` 代表陸地、`.` 代表海。上下左右相鄰的陸地屬於同一座島（斜對角不算）。請輸出島的數量，以及最大的島有幾格。

- **輸入**：第一行 R、C（1 ≤ R, C ≤ 1000）。接下來 R 行，每行一個長度 C 的字串。
- **輸出**：兩個整數，島的數量與最大島的格數。沒有陸地時輸出 `0 0`。

```text
範例輸入
4 5
##..#
#...#
..#..
.###.

範例輸出
3 4
```

左上角的島有 3 格、右上角的島有 2 格、下方的島有 4 格，所以共 3 座島，最大的有 4 格。
