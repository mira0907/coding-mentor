# 4B 帳本矛盾（困難）

出處：講義第四章 範例 4-B

有 n 個帳戶，餘額未知。依序收到 m 條紀錄，第 i 條為「a b c」，表示「帳戶 b 的餘額比帳戶 a 多 c」。請找出第一條與先前紀錄矛盾的紀錄編號；全部一致輸出 `-1`。

- **輸入**：第一行 n、m（1 ≤ n ≤ 10⁵，1 ≤ m ≤ 2×10⁵）。接下來 m 行 a、b、c（|c| ≤ 10⁹，a 可能等於 b）。
- **輸出**：第一條矛盾紀錄的編號，或 `-1`。

```text
範例輸入
3 4
1 2 5
2 3 3
1 3 8
3 1 -7

範例輸出
4
```

由前兩條可推出帳戶 1 比帳戶 3 少 8，第 3 條一致，第 4 條寫少 7 則矛盾。
