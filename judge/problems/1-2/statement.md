# 1-2 傳話遊戲（中等）

出處：講義第一章 實作 1-2

班上有 n 位同學玩傳話遊戲。第 i 位同學聽到消息後，一定會轉告第 a\_i 位同學。a\_i 可能等於 i，表示他只會說給自己聽。

某位同學 s 先想到一個消息，然後消息依規則一直傳下去。當消息傳到一位已經聽過的同學時，遊戲就結束。對每個 s = 1, 2, …, n，請算出從 s 開始時，總共有幾位不同的同學聽到消息（包含 s 自己）。

- **輸入**：第一行 n（1 ≤ n ≤ 2×10⁵）。第二行 n 個整數 a\_1 到 a\_n（1 ≤ a\_i ≤ n）。
- **輸出**：一行 n 個整數，第 s 個是從同學 s 開始時聽到消息的人數。

```text
範例輸入
6
2 3 1 3 4 6

範例輸出
3 3 3 4 5 1
```

同學 1、2、3 互傳成一圈，從他們開始都是 3 人；從 5 開始依序傳給 4、3、1、2，共 5 人；同學 6 只說給自己聽，只有 1 人。
