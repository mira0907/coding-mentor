# 4-2 颱風天的道路（中等）

出處：講義第四章 實作 4-2

n 個鄉鎮由 m 條雙向道路連接，第 i 條道路連接鄉鎮 u、v，耐風等級為 w。颱風等級為 x 時，耐風等級 w ≥ x 的道路照常通行，w < x 的道路全部封閉。

防災中心收到 q 筆詢問，每筆是「v x」：颱風等級為 x 時，從鄉鎮 v 出發可以到達幾個鄉鎮，包含 v 自己。每筆詢問各自獨立，互不影響。道路可能重複，也可能從鄉鎮連回自己。

- **輸入**：第一行 n、m、q（1 ≤ n ≤ 10⁵，0 ≤ m ≤ 10⁵，1 ≤ q ≤ 10⁵）。接下來 m 行，每行 u、v、w（1 ≤ u, v ≤ n，1 ≤ w ≤ 10⁹）。再接下來 q 行，每行 v、x（1 ≤ v ≤ n，1 ≤ x ≤ 10⁹）。
- **輸出**：q 行，依輸入順序輸出每筆詢問的答案。

```text
範例輸入
5 4 4
1 2 5
2 3 3
3 4 8
4 5 2
1 4
3 3
5 3
4 1

範例輸出
2
4
1
5
```

第一筆詢問的颱風等級是 4，只剩 1–2 與 3–4 兩條路能走，所以從鄉鎮 1 只到得了 1、2 兩個鄉鎮。
