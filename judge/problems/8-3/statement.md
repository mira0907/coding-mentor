# 8-3 騎士共存（困難）

出處：講義第八章 實作 8-3

棋藝社有一張 R × C 的棋盤，有些格子壞掉了，不能放棋子。社長想在棋盤上放最多的西洋棋騎士，而且任兩個騎士都不能互相攻擊。

騎士的走法和範例 2-A 相同：橫走 2 格再直走 1 格，或直走 2 格再橫走 1 格。一個騎士一步能跳到另一個騎士所在的格子，兩者就互相攻擊。壞掉的格子只是不能放，不會擋住攻擊；每格最多放一個騎士。

- **輸入**：第一行 R、C（1 ≤ R, C ≤ 200）。接下來 R 行，每行一個長度 C 的字串，`.` 是可以放的格子，`#` 是壞掉的格子。
- **輸出**：一個整數，最多能放的騎士數。所有格子都壞掉時輸出 0。

```text
範例輸入
3 3
#..
...
...

範例輸出
5
```

放在四個邊的中點和正中央共 5 個，彼此都不會攻擊，而且沒辦法放到 6 個。
