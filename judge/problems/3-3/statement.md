# 3-3 救護車路線（困難）

出處：講義第三章 實作 3-3

市區有 n 個路口與 m 條單向道路。第 i 條道路從路口 u\_i 通往 v\_i，要開 w\_i 分鐘。醫院在路口 s，災區在路口 t。

救護車一定走花費時間最少的路線，但這樣的最短路線可能不只一條。兩條路線只要經過的道路不同，就算不同的路線。交通局想替每條道路分級：

- `ALL`：每一條最短路線都經過它。也就是說，只封閉這條路，s 到 t 的最短時間就會變長，或根本到不了。
- `SOME`：有些最短路線經過它，有些沒有。
- `NONE`：沒有任何最短路線經過它。

道路可能重複，重複的道路視為不同的道路。道路也可能從路口連回自己。若從 s 根本到不了 t，所有道路都是 `NONE`。

- **輸入**：第一行 n、m、s、t（2 ≤ n ≤ 10⁵，0 ≤ m ≤ 2×10⁵，1 ≤ s, t ≤ n，s ≠ t）。接下來 m 行，第 i 行是 u\_i、v\_i、w\_i（1 ≤ u\_i, v\_i ≤ n，1 ≤ w\_i ≤ 10⁹），道路依輸入順序編為 1 到 m。
- **輸出**：m 行，第 i 行是第 i 條道路的等級：`ALL`、`SOME` 或 `NONE`。

```text
範例輸入
5 7 1 5
1 2 2
1 3 2
2 4 1
3 4 1
4 5 3
2 5 5
3 2 1

範例輸出
SOME
SOME
SOME
SOME
ALL
NONE
NONE
```

最短時間是 6 分鐘，最短路線有 1 → 2 → 4 → 5 與 1 → 3 → 4 → 5 兩條，只有第 5 條道路 4 → 5 是兩條都會經過的。
