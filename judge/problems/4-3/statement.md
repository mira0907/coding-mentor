# 4-3 光纖網路（困難）

出處：講義第四章 實作 4-3

電信公司有 n 個機房與 m 條可以鋪設的光纖，第 i 條連接機房 u\_i、v\_i，成本 w\_i。公司要選 n − 1 條光纖讓所有機房互通，而且總成本最小，也就是選一棵最小生成樹。

總成本最小的選法可能不只一種。請替每條光纖分級：

- `ALL`：每一種總成本最小的選法都會用到它。
- `SOME`：有些總成本最小的選法用到它，有些沒有。
- `NONE`：任何總成本最小的選法都不會用到它。

保證所有機房可以互通。光纖可能重複，重複的光纖視為不同的光纖。光纖也可能從機房連回自己。

- **輸入**：第一行 n、m（1 ≤ n ≤ 10⁵，n − 1 ≤ m ≤ 2×10⁵）。接下來 m 行，第 i 行是 u\_i、v\_i、w\_i（1 ≤ u\_i, v\_i ≤ n，1 ≤ w\_i ≤ 10⁹），光纖依輸入順序編為 1 到 m。
- **輸出**：m 行，第 i 行是第 i 條光纖的等級：`ALL`、`SOME` 或 `NONE`。

```text
範例輸入
5 7
1 2 1
2 3 1
3 1 1
3 4 2
4 5 2
2 5 3
1 1 4

範例輸出
SOME
SOME
SOME
ALL
ALL
NONE
NONE
```

前三條光纖是成本都為 1 的三角形，任選兩條都行，所以都是 `SOME`；第 6 條連接的 2、5 早已互通，第 7 條連回自己，所以都是 `NONE`。
