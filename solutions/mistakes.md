# 我的錯誤清單

每次 WA、RE 或卡住，把「錯誤類型」記在這裡。送出前照這份清單檢查一遍。

| 錯誤 | 症狀 | 檢查方式 | 出現在 |
|------|------|----------|--------|
| 讀到 `n` 之前就用 `n` 建立 vector | 陣列大小亂掉、RE 或怪答案 | 宣告 vector 的那一行，`n` 已經 `cin` 過了嗎？ | 1-2 |
| 對空的 vector 取 `v[0]` | RE | 取 `v[0]`、`v.back()` 之前，可能是空的嗎？ | 1-1 |
| `a = b++` 以為會拿到加一後的值 | 答案差 1，而且 `b` 也被改掉 | 只想要加一後的值就寫 `b + 1` | 1-2 |
| 迴圈裡呼叫 `find` | TLE，複雜度多乘了一個 n 或 m | 迴圈裡有沒有 `find`、`count`？能不能先標記在陣列上，改成 O(1) 查詢？ | 1-3 |
| 在迴圈裡開長度 n 的陣列 | 跑 n 次就變成 O(n²)，可能 TLE | `vector<...> x(n)` 寫在迴圈裡面嗎？能不能開在外面重複使用？ | 1-3 |
| `find(..., {x, y})` 直接傳大括號 | 編譯錯誤 `no matching function for call to 'find'` | 寫成 `pair<int,int>{x, y}` 或 `make_pair(x, y)` | 1-3 |
| 兩個陣列的編號一個從 0、一個從 1 開始 | 範例答案就錯 | 讀入時統一 `a-1`，所有陣列都用 0 開始的編號 | 1-3 |
| 無向邊只存或只查一個方向 | WA | 「u v」和「v u」都要處理到嗎？ | 1-3 |
| `continue` 跳過了迴圈尾端必要的動作 | 無窮迴圈或答案錯 | `continue` 後面是不是有 `pop()`、`i++` 之類一定要做的事？ | 1-3 |
| 巢狀迴圈寫錯變數，例如 `for(j=0;j<n;i++)` | 無窮迴圈 | 每個 for 的三個部分，用的是同一個變數嗎？ | 1-3 |
