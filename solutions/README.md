# 講義題目的解答

把講義題目的解答放在這裡，檔名用題號，例如 `3-1.cpp`、`1A.cpp`。

- 建立新檔：`./scripts/judge.sh new 3-1`（會複製模板並顯示題目）
- 評測：`./scripts/judge.sh solutions/3-1.cpp`，或在 VS Code 執行「Judge current file」任務

## 練習紀錄

每題 AC 後花 5 分鐘填 `<題號>.md`（`judge.sh new` 會自動從 [_template.md](_template.md) 建立）：

- **卡住的地方**：具體寫出錯在哪裡，不是「沒想到」。
- **下次看到什麼，就想到什麼**：把題目特徵連到解法，這是下次最用得上的部分。
- **寫程式時犯的錯**：新的錯誤類型也加到 [mistakes.md](mistakes.md)，送出前照著檢查。
- **下次複習**：AC 後 3 天、再 2 週，不看程式重寫一次。寫得出來才算真的學會。

題號對照請看 `./scripts/judge.sh list`。
